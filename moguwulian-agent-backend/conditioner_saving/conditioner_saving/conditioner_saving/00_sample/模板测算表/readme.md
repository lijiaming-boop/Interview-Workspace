# 节能评估表模板说明

## 文件清单

### 1. 节能评估表-按冷站电量数据-标准版.xlsx
- **适用范围**: 标准空调站房
- **特征**: 仅有一次冷冻泵，无二次泵分离
- **Sheet结构**: 3个sheet（上限/下限/气象数据）
- **不适用**: 包含热水泵、水蓄冷、二次泵、中低温机组的空调站房

### 2. 节能评估表-按冷站电量数据-二次泵版.xlsx
- **适用范围**: 冷冻系统包含二次泵的空调站房
- **特征**: 冷冻泵分为一次泵和二次泵
- **Sheet结构**: 3个sheet（上限/下限/气象数据）
- **不适用**: 包含热水泵、水蓄冷、中低温机组的空调站房

## Sheet结构说明

每个模板包含3个sheet：

1. **【1】按冷站电量数据-上限**
   - 用途：估算节能率上限（理想情况）
   - 特点：基于最优运行条件，理想化假设
   - 适用：了解项目最大节能潜力

2. **【2】按冷站电量数据-下限**
   - 用途：估算节能率下限（保守估计）
   - 特点：基于常规优化参数，考虑实际约束
   - 适用：风险控制，保守承诺

3. **全国主要城市气象情况**
   - 用途：提供各地区湿球温度等气象数据
   - 特点：辅助上限和下限的计算

## 自动识别和计算机制

系统会根据调研表内容**自动识别站房类型**并选择对应模板：

- 检测到"一次泵"/"二次泵"关键词 → 使用二次泵版
- 未检测到分离泵特征 → 使用标准版
- 检测到热水泵/水蓄冷/中低温机组 → 自动拦截，不支持

**节能率范围计算**：
- 系统自动计算上限和下限两个sheet
- 输出节能率范围：下限% - 上限%
- 实际节能效果通常在此范围内

## 不支持的特殊类型

以下类型的空调站房**不在自动评估范围内**：

- ❌ 包含热水泵的站房
- ❌ 包含水蓄冷/冰蓄冷系统的站房
- ❌ 包含中低温机组的站房

这些特殊类型需要专门的节能评估方法，系统会在数据提取阶段自动识别并拦截。
