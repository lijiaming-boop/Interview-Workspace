## 六、计算步骤

### 6.1 派生参数计算

**6.1.1 智控后平均压力**`postControlPressure = alarmPressureLowerLimit + safetyMargin + pressureFluctuation`

**6.1.2 压力降低值**`deltaPressure = averagePressure - postControlPressure`

**6.1.3 空气消耗降低百分比**`airReductionPercent = 100 × (1 - (postControlPressure + atm) / (averagePressure + atm))`

**6.1.4 空气流量降低值**`deltaFlowRate = systemCompressedAirFlow × (airReductionPercent / 100) × (directUseRatio / 100)`

**6.1.5 平均年运行时间**   若 `dailyRunningHours` 和 `annualRunningDays` 均非空且计算结果在 (0, 8760\] 内：   `averageAnnualOperatingHours = dailyRunningHours × annualRunningDays`   否则：   `averageAnnualOperatingHours = 8500`（并触发置信度扣分）

### 6.2 实际年总能耗（MWh）

`E_original_MWh = totalAnnualEnergyConsumption / 1000`

### 6.3 节能量（MWh）

**6.3.1 压力降低节能量**`E_pressure = deltaPressure × systemCompressorPowerFactor × systemCompressedAirFlow × averageAnnualOperatingHours / 1000`

**6.3.2 空气消耗降低节能量**`E_air = deltaFlowRate × systemSpecificPower × averageAnnualOperatingHours / 1000`

**6.3.3 总节能量**`E_total_MWh = E_pressure + E_air`

### 6.4 节能率（%）

`energySavingRate = (E_total_MWh / E_original_MWh) × 100`

### 6.5 年节能收益（元）

`annualSavings = E_total_MWh × 1000 × electricityPrice`

## 七、置信度与场景处理

### 7.1 置信度计算

置信度由原始数据缺失/推算情况累计决定（从100%开始扣减）。扣分规则如下：

| 异常项 | 扣分幅度 |
| --- | --- |
| 压力曲线数据7~14天（不足14天） | \-5% |
| 行业缺失（压力波动用默认0.20） | \-15% |
| 每台（运行+备用）功率因子使用默认0.35 | \-5%/台（最多-30%） |
| 每台运行设备负载率AI推算 | \-5%/台（最多-30%） |
| 电价缺失（城市推算） | \-10% |
| 月度能耗每缺一月填充 | \-5%/月 |
| 每天开机时间缺失（默认10） | \-5% |
| 年运行天数缺失（默认330） | \-5% |
| 年运行时间计算异常（用默认8500） | \-10% |

最终置信度 = max(0, 100 - 总扣分)。  输出时前端显示：**“高”**（≥80%）、**“中”**（60~79%）、**“低”**（<60%）。

### 7.2 保守、中性、乐观节能率

中性节能率即上述 `energySavingRate`。

*   **保守节能率** = 基准节能率 × 0.85
    
*   **乐观节能率** = 基准节能率 × 1.15
    

### 7.3 分项节能量

*   压力降低节能量：`E_pressure`
    
*   空气消耗降低节能量：`E_air`
