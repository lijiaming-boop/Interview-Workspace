# 示例文件说明：

文件名：【齐全】15.2%惠州光弘-中央空调节能调研表.xlsx
- 调研表数据填写齐全
- 节能率测算结果是15.2%

文件名：【仅有夏季】6.5%和光同程-机房智能化调研表2023年5月版.xlsx
- 调研表只填了夏季数据
- 节能率测算结果是6.5%
- 总共16台冷机，6台低温机组+2台中温机组+8台热回收机组。热回收机组一般都兼中温机使用。
- 冷机运行台数写5+8的意思是，开了5台低温机组+8台中温机组
- 冷机供水温度写7.5+13.5的意思是，低温出水7.5℃，中温出水13.5℃31分钟前

文件名：【缺冬季】10.4%石家庄仁和药业中央空调节能调研表.xlsx
- 调研表没有填冬季数据
- 节能率测算结果是10.4%

文件名：【缺夏季】12.1%上海和元-机房智能化调研表模板（深度调研）.xlsx
- 调研表没有填夏季的能耗数据，这个要看sheet1，那里面是能耗数据
- 节能率测算结果是12.1%

文件名：【参差不齐】11.9%中央空调节能调研表（首页含问题指引）.xlsx
- 调研表填的参差不齐，按月份间隔着填写
- 节能率测算结果是11.9%

文件名：【数据缺失过多 无法计算节能率】02-中央空调节能调研表（首页含问题指引）-工业板块.xlsx
- 这是调研表模板，很多数据缺失
- 因为数据缺失过多，无法计算节能率
