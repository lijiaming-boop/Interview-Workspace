# 空调节能率智能测算工具 - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品背景

在中央空调销售和解决方案制定过程中，AR（销售）和SR（解决方案专家）面临协作效率低下的问题：

- AR抱怨SR响应慢，方案出具周期长
- SR抱怨AR填写的调研表数据质量差，反复沟通确认
- 人工测算耗时长，缺乏标准化流程

### 1.2 产品定位

一款智能化的空调节能率测算工具，帮助销售和解决方案团队快速、准确地完成节能率评估。

### 1.3 目标用户

- **主要用户**：AR（销售代表）、SR（解决方案专家）
- **次要用户**：技术支持人员、管理人员

### 1.4 产品价值

- **提升效率**：AR可自助完成基础测算，SR只需审核确认
- **改善质量**：标准化测算流程，数据质量智能检查
- **降低成本**：减少人工沟通和返工成本
- **节能率准确**：测算偏差≤2%（核心目标）

## 2. 用户故事

### 2.1 AR（销售）用户故事

**作为销售代表，我希望**：

- 上传填好的调研表，系统自动计算节能率
- 系统能告诉我哪些数据有问题或缺失
- 快速获得节能率范围和风险说明，用于客户沟通

**验收标准**：

- 上传到获得结果≤1分钟
- 能识别常见的数据质量问题（缺失、异常值）
- 输出节能率范围和置信度说明

### 2.2 SR（解决方案专家）用户故事

**作为解决方案专家，我希望**：

- 查看AR测算的结果和计算依据
- 看到数据质量评估，判断结果可靠性
- 必要时手动调整参数，重新计算

**验收标准**：

- 能看到完整的计算过程和中间结果
- 计算逻辑透明可追溯
- 可以修改关键参数并重算

## 3. 核心功能需求

### 3.1 数据输入功能

#### 3.1.1 调研表上传

**功能描述**：用户上传Excel格式的调研表

- 支持文件选择器上传
- 文件大小限制≤10MB
- 支持.xlsx格式

#### 3.1.2 数据自动提取

**功能描述**：系统根据标准模板提取数据

- 基于参考模板（00_sample/02-中央空调节能调研表）
- 自动提取关键数据：
  - 基本信息：车间环境要求（温度、湿度）
  - 设备清单：冷机、冷却泵、冷冻泵、冷却塔参数
  - 运行规律：逐月的水温、泵频率、塔频率（行36-44）
  - 用电数据：逐月耗电量（行47）
- MVP阶段仅支持标准模板格式

### 3.2 数据质量检查

#### 3.2.1 数据完整性检查

**功能描述**：检查逐月数据的缺失情况

- 识别12个月中哪些月份数据缺失
- 判断缺失数据能否补全（如：只有夏季数据，其他月份可插值）
- 计算数据完整度百分比

#### 3.2.2 数据合理性检查

**功能描述**：检查数据是否在合理范围内

- 温度范围检查（冷冻水7-12°C，冷却水28-37°C）
- 频率范围检查（20-50Hz）
- 湿度范围检查（30-70%）
- 耗电量异常检查（同比波动>50%标记为异常）

#### 3.2.3 风险提示

**功能描述**：根据数据质量给出风险说明

- 数据完整度<50%：高风险，建议补充数据
- 数据完整度50-80%：中风险，可用插值补全
- 数据完整度>80%：低风险，可直接计算
- 列出所有需要注意的数据问题

### 3.3 智能计算

#### 3.3.1 数据补全

**功能描述**：对缺失数据进行补全

- **季节代表月法**：夏季用7月，春秋用5月/10月，冬季用1月
- **线性插值法**：当有部分月份数据时，插值估算缺失月份
- **补全规则**：
  - 如果有夏季数据（6-8月），可用插值推算其他季节
  - 如果某季节完全缺失，使用相邻季节数据估算
- 补全后的数据需标注"（估算值）"

#### 3.3.2 节能率测算

**功能描述**：基于输入数据计算节能率

- **核心公式**：需要从专家处获取真实的节能率计算公式（待补充）
- **特殊条件处理**：
  - 湿度<40%时，节能率需乘以折算系数（约0.4-0.6）
  - 不同季节的能耗权重不同
- **输出结果**：
  - 节能率范围（最低-推荐-最高）
  - 置信度说明
  - 影响节能率的关键因素

### 3.4 结果展示

#### 3.4.1 测算结果展示

**功能描述**：清晰展示计算结果

- **节能率范围**：最低值-推荐值-最高值
- **置信度**：高/中/低（基于数据完整度）
- **风险说明**：列出影响结果准确性的因素
- **数据质量报告**：显示哪些数据是实测的，哪些是估算的

#### 3.4.2 计算过程展示

**功能描述**：透明展示计算逻辑（供SR审核）

- 显示关键中间结果
- 显示使用的公式和参数
- 显示数据补全的具体方法
- 支持参数调整后重新计算

### 3.5 结果导出（P1功能，V1.0实现）

#### 3.5.1 简要报告

**功能描述**：生成PDF格式的测算报告

- 项目基本信息
- 节能率测算结果
- 数据质量说明
- 风险提示

## 12. 核心算法说明

**公式来源**：00_sample/机房智能化节能评估表-按冷站电量数据.xlsx

**适用场景**：仅有冷站逐月总电量数据，无各设备单独电表

### 12.1 计算前提和假设

#### 12.1.1 能耗分解假设

由于只有冷站总电量，通过固定占比估算各设备能耗：

| 设备  | 能耗占比 | 说明     |
| --- | ---- | ------ |
| 冷机  | 65%  | 主要耗能设备 |
| 冷却泵 | 20%  | 次要耗能设备 |
| 冷冻泵 | 10%  | 次要耗能设备 |
| 冷却塔 | 5%   | 最小耗能设备 |

**计算公式**：

```
冷机能耗(月) = 冷站总能耗(月) × 0.65
冷却泵能耗(月) = 冷站总能耗(月) × 0.20
冷冻泵能耗(月) = 冷站总能耗(月) × 0.10
冷却塔能耗(月) = 冷站总能耗(月) × 0.05
```

#### 12.1.2 固定参数配置

| 参数名称    | 数值   | 用途      |
| ------- | ---- | ------- |
| 冷却水额定温差 | 5℃   | 泵变频优化基准 |
| 冷冻水额定温差 | 5℃   | 泵变频优化基准 |
| 冷却泵最小频率 | 35Hz | 变频下限    |
| 冷冻泵最小频率 | 35Hz | 变频下限    |

### 12.2 节能率计算公式

**总体公式**：

```
节能率 = Σ(1-12月节能量) / Σ(1-12月总能耗) × 100%

月节能量 = 冷机节能量 + 冷却泵节能量 + 冷冻泵节能量 + 冷却塔节能量
```

#### 12.2.1 冷机节能量（供水温度优化）

**步骤1：预计优化后的供水温度**

根据用户当前供水温度，预测优化空间（温度越低，优化空间越大）：

```python
IF 用户供水温度 < 8.5℃:
    预计供水温度 = 用户供水温度 + 5℃
ELIF 用户供水温度 < 10℃:
    预计供水温度 = 用户供水温度 + 4℃
ELIF 用户供水温度 < 12℃:
    预计供水温度 = 用户供水温度 + 3℃
ELSE:
    预计供水温度 = 用户供水温度 + 2℃
```

**步骤2：计算节能量**

**核心公式**：

```
冷机节能量(月) = 冷机能耗(月) × (预计供水温度 - 用户供水温度) × 0.04
```

**核心系数**：供水温度每提高1℃，冷机能耗降低**4%**

**物理依据**：提高供水温度可提高蒸发温度，改善制冷循环效率

#### 12.2.2 冷却泵节能量（变频优化）

**步骤1：预计优化后的运行频率**

根据冷却侧供回水温差判断流量是否过大：

```python
IF 冷却侧供回水温差 <= 5℃:  # 温差小说明流量过大
    预计频率 = 用户频率 × (实际温差 / 5)

    # 限制在合理范围
    IF 预计频率 < 35Hz:
        预计频率 = 35Hz  # 最小频率
    IF 预计频率 > 50Hz:
        预计频率 = 50Hz  # 工频上限
ELSE:
    预计频率 = 用户频率  # 不优化
```

**步骤2：计算节能量**

**核心公式**：

```
冷却泵节能量(月) = 冷却泵能耗(月) × (1 - (预计频率/用户频率)^2.5)
```

**核心系数**：泵的能耗 ∝ 频率^**2.5**

**物理依据**：泵的相似定律（能耗与转速的2.5-3次方成正比）

#### 12.2.3 冷冻泵节能量（变频优化）

**逻辑完全同冷却泵**：

```python
IF 冷冻侧供回水温差 <= 5℃:
    预计频率 = 用户频率 × (实际温差 / 5)
    预计频率 = max(35, min(50, 预计频率))
ELSE:
    预计频率 = 用户频率

冷冻泵节能量(月) = 冷冻泵能耗(月) × (1 - (预计频率/用户频率)^2.5)
```

#### 12.2.4 冷却塔节能量（出水温度优化）

**步骤1：查询预计冷却塔出水温度**

根据项目所在地区，查询对应的气象数据：

```python
预计出水温度 = 当地湿球温度 + 4.5℃
预计出水温度 = max(21, 预计出水温度)  # 最低21℃
```

**气象数据映射**：

| 地区  | 参考城市 | 数据来源      |
| --- | ---- | --------- |
| 华南  | 广州   | 气象表行3-6   |
| 华东  | 上海   | 气象表行7-10  |
| 华中  | 武汉   | 气象表行11-14 |
| 西南  | 成都   | 气象表行15-18 |
| 西北  | 西安   | 气象表行19-22 |
| 华北  | 济南   | 气象表行23-26 |

**步骤2：计算因冷却塔优化产生的冷机节能量**

**核心公式**：

```python
IF 预计出水温度 < 用户出水温度:
    冷却塔节能量(月) = 冷机能耗(月) × 0.015 × (用户出水温度 - 预计出水温度)
ELSE:
    冷却塔节能量(月) = 0
```

**核心系数**：冷却塔出水温度每降低1℃，冷机能耗降低**1.5%**

**物理依据**：降低冷却水温度可降低冷凝温度，提高冷机COP

### 12.3 数据补全算法

#### 12.3.1 季节代表月法（MVP实现）

当某些月份数据缺失时，使用代表月数据填充：

| 季节  | 代表月份 | 覆盖月份             |
| --- | ---- | ---------------- |
| 夏季  | 7月   | 6月、7月、8月         |
| 春季  | 5月   | 4月、5月            |
| 秋季  | 10月  | 9月、10月           |
| 冬季  | 1月   | 11月、12月、1月、2月、3月 |

**补全规则**：

- 标注补全的数据为"（估算值）"
- 降低该月数据的置信度
- 在风险说明中提示数据质量影响

#### 12.3.2 线性插值法（V1.0实现）

当有部分连续月份数据时，使用线性插值：

```python
# 示例：已知5月和8月数据，插值6月、7月
缺失月数据 = 前月数据 + (后月数据 - 前月数据) × (月份差 / 总月份差)
```

**适用条件**：

- 前后月份数据均存在
- 月份跨度 ≤ 3个月
- 非跨季节插值（如12月到2月不适用线性插值）

#### 12.3.3 补全数据置信度

| 数据类型   | 置信度等级   | 说明       |
| ------ | ------- | -------- |
| 实测数据   | 高（95%）  | 直接来自调研表  |
| 季节代表月  | 中（75%）  | 用代表月填充   |
| 线性插值   | 中低（60%） | 基于已有数据插值 |
| 缺失>50% | 低（<50%） | 建议补充数据   |

### 12.4 节能率范围的计算逻辑

**核心思想**：由于数据不完整或有估算成分，应给出节能率范围，而非单一值。

#### 12.4.1 范围计算方法

**最低值（保守估计）**：

```python
节能率_最低 = Σ(月节能量 × 0.8) / Σ(月总能耗) × 100%
```

- 对所有优化效果打8折
- 数据补全时使用较差假设
- 适用于风险评估和保守承诺

**推荐值（正常估计）**：

```python
节能率_推荐 = Σ(月节能量) / Σ(月总能耗) × 100%
```

- 使用标准系数计算
- 最可能的节能率
- 用于方案报价和合同签订

**最高值（乐观估计）**：

```python
节能率_最高 = Σ(月节能量 × 1.2) / Σ(月总能耗) × 100%
```

- 对所有优化效果上浮20%
- 假设优化到理想状态
- 适用于潜力分析和技术交流

#### 12.4.2 置信度判断

基于数据完整度判断结果可靠性：

| 数据完整度  | 置信度 | 说明        |
| ------ | --- | --------- |
| >80%   | 高   | 可直接使用     |
| 50-80% | 中   | 需标注数据来源   |
| <50%   | 低   | 建议补充数据后重算 |

**数据完整度计算**：

```python
数据完整度 = 实测数据月份数 / 12 × 100%
```

### 12.6 边界条件和异常处理

#### 12.6.1 数据有效性检查

**必检项**：

- 冷站总能耗 > 0
- 供回水温差 > 0（否则变频公式异常）
- 运行频率在20-50Hz范围内
- 温度数据在合理范围（-20℃ ~ 50℃）

#### 12.6.2 计算边界限制

**频率限制**：

```python
预计频率 = max(35, min(50, 计算值))
```

**温度限制**：

```python
预计供水温度 >= 用户供水温度  # 不能降温
冷却塔出水温度 >= 21℃  # 物理下限
```

#### 12.6.3 异常情况处理

| 异常情况      | 处理方式           |
| --------- | -------------- |
| 温差 ≤ 0    | 跳过该月泵变频优化      |
| 能耗 = 0    | 标记为停机月，不参与计算   |
| 数据超出合理范围  | 标记为异常，提示人工确认   |
| 节能率 > 50% | 标记为可疑，建议复核     |
| 节能率 < 0   | 标记为计算错误，检查输入数据 |
