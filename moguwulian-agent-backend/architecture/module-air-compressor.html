空压模块 · 空压机节能率智能测算

moduleType = air_compressor · “上传 → 提取 → 建议 → 计算 → 完成”
前端 Next.js 16 后端 FastAPI 存储/会话底座 外部模型服务 技能/消息通道 请求/数据 异步 SSE / 轮询 / 回传 主流程调用

职责边界

  • 负责：空压调研表上传 → LLM 非结构化提取 → 质检/填充建议 → 节能率与设备分析计算 → 报价单/方案文档下载。
  • 不负责：计算全部走确定性引擎，LLM 只做“看得懂”的文本提取与建议叙事；无“进入冷站仿真”出口（仅空调有）。

核心数据流

  • 调研表 → /api/upload（建 session）→ extract-air-compressor-data-llm 技能 → rawData(projectLevel/equipmentLevel) → 服务端 schema 校验/拒收复评。
  • 建议脚本 + 可选 LLM 增强 → 回填 → AirCompressorCalculator（current − optimized）→ 节能率区间 + 设备分析 JSON。
  • 全程 SSE 推送步骤日志；结果经 GET /api/result/{session_id} 轮询取回展示。

模块间依赖

  • 依赖共享：lib/api.ts 契约、FastAPI 分阶段端点、M1 会话/锁/事件底座、外部 Anthropic API。
  • 平行：与空调模块共用 Workflow.tsx 骨架；与报价模块无会话级耦合；与仿真/设备拓扑模块无数据交换。
