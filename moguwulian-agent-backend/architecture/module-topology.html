设备拓扑模块 · 冷站性能仿真输入链（plant_simulation）

“拓扑 → COP 曲线 → 运行工况 → 8760h 仿真” · 旧站房含基准电量与多方案对比
前端 SimulationWorkflow / sim 四阶段 后端 FastAPI / 参考引擎 技能契约 plant-simulation 会话状态/产物 外部模型 / 上游模块 请求/数据 异步 / 状态轮询 阶段推进（主链）

职责边界

  • 负责：设备拓扑的采集、解析、编辑与校验，作为冷站仿真链第一阶段输入；随后 COP 曲线、运行工况、8760h 仿真与多方案对比。
  • 不负责：拓扑数据仅服务于仿真会话；空调/空压/报价管线不复用该结构；FastAPI 不引用 simulation/ 遗留引擎。

核心数据流

  • 调研表/文本 → _normalize_topology 归一化 → sim_topology 落库；COP 曲线/默认表 → sim_cop_data；工况与（old_station）baseline/schemes → sim_operating_conditions。
  • execute → Skill 动态代码 → sim_output/（summary/逐时/报告）；fetchSimResult 轮询并展示结果与多方案对比。

模块间依赖

  • 上游依赖：空调模块（节能率 + source_session_id，页级 state + 后端复制调研表）。
  • 共享：lib/api.ts sim 组、FastAPI /sim、M1 底座、外部 Anthropic。
  • 独立：与报价模块、空压模块无数据交换。
