报价模块 · 标准能管智能报价（quote）

独立子系统 · “上传 → 预检 → AI/本地解析 → 项目复核 → 底稿计算 → 逐项审核 → 生成下载”
前端 QuoteWorkflow 后端 FastAPI / quote_module 会话/产物 技能/规则脚本 外部模型服务 请求/数据 异步 / 降级路径 主流程调用

职责边界

  • 负责：标准能管报价的完整闭环——调研表解析（AI/本地）、预检、项目复核、底稿计算、人工逐项审核、报价表与方案文档生成。
  • 不负责：不接管空调/空压的节能计算产物（它们各自的报价单由各自管线生成）；不入 agent 统一编排；非标风险项必须人工确认而非自动放行。

核心数据流

  • 调研表 → project_data（含 optional_modules / logic_gaps）→ bottom_sheet_{id}.json（software/hardware/construction + totals + status_summary）。
  • 审核台 PUT /api/quote/audit/{id} 逐项改状态/选候选/改价；section9_analyzer 把“AI/闭环/节能承诺”等判为 NONSTANDARD。
  • 生成：标准价/渠道价 xlsx + 技术方案 docx → /api/quote/download。

模块间依赖

  • 共享：FastAPI /api、M1 会话/锁/事件底座、lib/api.ts、外部 LLM（OpenAI 兼容通道）。
  • 与空调/空压/仿真无会话级耦合；依赖价目表产物 quote_module/outputs/price_catalog.json。
